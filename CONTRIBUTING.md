# Contributing

Use the setup and checks in [README](./README.md). Keep parsing, API, graph projection and presentation changes separate where practical. Add synthetic regression cases for dependency and code-evidence changes. UI fixes should preserve the existing Chinese terminology and three-pane workflow.

Never submit real Qlik exports, connection strings, user names, internal hostnames, generated reports or business screenshots. Reproduce issues with a small synthetic script and JSON objects generated in a temporary directory. Tests must run without access to any organization environment.

Run the public-content check before opening a PR. Explain the behavior change, validation and any static-analysis limitations. Retain the upstream license and dependency attributions.
